# Index des sections locales

Cette page sert à capter le maximum de sections locales sans mélanger les niveaux. Les sections locales doivent être rattachées à leur parent immédiat : syndicat national, division provinciale, district, fédération sectorielle ou centrale.

## Principes de classement

| Niveau | Exemple | Classement recommandé |
|---|---|---|
| Syndicat national | [[Unifor]], [[SCFP-CUPE]], [[Teamsters]] | Page centrale ou syndicat-mère |
| Division provinciale | [[CUPE-ON]], [[CUPE-BC]], SCFP-Québec | Page fédérations/divisions |
| District | Métallos District 5, Teamsters Joint Council 91 | Sous le syndicat national |
| Section locale | Local 106, Local 500, Local 9490 | Ici et dans la page parent |
| Bureau | Bureau Montréal, bureau Québec | Ne pas compter comme local |
| Employeur | IGA, CIUSSS, municipalité | Niveau de prospection, pas niveau syndical |
